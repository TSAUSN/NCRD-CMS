# Glossary

Plain meanings for words the guides and screens use.

For: Editors, site admins and maintainers. Last checked: 2026-11-04.

| Word | Meaning |
| --- | --- |
| Draft | Your saved, private version of a page, story, list or setting. Visitors never see it. |
| Save draft | Saves your work privately. It never changes the public site. |
| Live, published version | What visitors see now. |
| Changes not live | There is a saved draft that differs from the live version. |
| Version | One saved state of something. Every save adds a version; old versions are kept and never changed. That is what lets History restore them. |
| Restore as new draft | Copies an older version into a new private draft. The live version does not change until that draft is published. |
| Review | Reading exactly what will change, and the publishing checks, before publishing. |
| Publishing checks | Problems the CMS finds before publishing, such as missing image descriptions or leftover sample text. Some can be published with a recorded reason. |
| Release | A set of reviewed changes published together. |
| Schedule, Publish later | Publish a reviewed release at a chosen time. The exact reviewed versions are kept (pinned) for that time; later edits need their own review. |
| Pinned | Fixed to one exact version, so later edits cannot slip in unreviewed. |
| Sample content | Placeholder text or pictures a template starts with, shown in square brackets. Checks flag it before publishing. |
| Section | One block of a page, such as a hero, cards or an FAQ, added from the shared library. |
| Shared areas, frame | The header, menu and footer every page of a site uses. Site admins change them on their own screens. |
| National template | The shared design SAWSO and Echelon pages use, with each site's own logo, menu and content. |
| Native site | A site built with the CMS's own sections and template. |
| Imported site | A site brought in with its original design files, such as Better Together 2027. It keeps its own look and some screens differ. |
| Chapter | An Echelon chapter's page, edited by its own volunteers, with shared parts protected. |
| Division approval | Chapter volunteers send changes to their division, which approves and publishes them. |
| Data value | A number saved once, with its source, and shown on every page that uses it. |
| Retained demo | The long-running local copy of the CMS used for demonstrations. It is not a hosted site. |
| Staging, preview link | A private test address for review before a site goes live on its real domain. |
