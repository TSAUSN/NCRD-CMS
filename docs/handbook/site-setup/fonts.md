# Fonts

Connect the approved Adobe kit, check the staging address and save font choices as a private draft.

For: Site admins and Super admins. Last checked: 2026-10-31.

Open Site look, then Fonts. The approved stylesheet is
`https://use.typekit.net/euh2hvn.css`. Check kit opens a private preview on this
site’s staging address and checks the four font families through normal browser
font loading. No fonts are uploaded, downloaded into the repository or bundled.
An arbitrary stylesheet link is refused.

SAWSO uses Trajan Pro 3 headings and Proxima Nova body text. Echelon keeps its
sans-serif headings; Trajan is hidden for chapters and refused by the database.
The approved kit also includes Proxima Nova Condensed and Extra Condensed.
Buttons follow the selected body family and the national template’s weight;
the approved public CSS determines weight rather than a separate font-weight
control in this screen.

Save draft stores the choices without changing the public site. Publish opens
a review step, then the existing Publish workspace. A conflicting save asks you
to reload; another person’s saved choices are not overwritten.

The connection reports only the address actually checked. A live address says
Check at launch. A failed font check keeps the template’s stand-ins and explains
that either the Adobe account’s allowed-address list or the network needs
attention. Ask the Adobe account owner to add the displayed hostname, then press
Check again. This CMS does not change the Adobe account or buy a licence.

The CSS kit loads only for exact hostnames recorded in this site’s theme. Its
policy permits styles from use.typekit.net and p.typekit.net, fonts from
use.typekit.net, and the kit’s licensing image from p.typekit.net. Adobe scripts
and optional metrics services are not enabled. Existing imported-site styles
and policies remain unchanged.

Earlier local verification: the retained SAWSO staging address loads Trajan Pro 3 and
Proxima Nova after the normal selected-theme review and publication. All page
heads, story list heads and other sites’ theme heads remained unchanged. The
connected and unavailable admin states were checked at 1440 and 1024, and the
public specimen at 1440, 1024 and 390. This does not complete the wider Site look
or sidebar design pass.

Needs administrator input: verify the kit entitlement and final staging/production addresses
in the Adobe account before hosted use. The local browser check does not prove
those future addresses work. Echelon’s supplied local font licence still needs
confirmation for hosted use. No Google project or hosting change was made.

Private previews use the same approved font resource hosts as public pages. The
editing canvas, scriptless saved preview and copied preview frames keep their
existing script restrictions. A new private site retains its staging address for
font-kit selection even before its first publication. The actual browser address
still needs to be allowed by Adobe; an account or network rejection uses the
existing stand-ins. Preview policy permissions do not grant Adobe entitlement.

If you choose another CMS screen with unfinished font choices, Keep editing
returns to them. Save draft and leave checks the kit link and saves the normal
private site-look draft before opening that destination. Use Check kit before
saving a new connection. Invalid links or failed saves keep the fields here.
Discard changes restores the saved font choices and approved kit field. A
private save still waits for Publish; stand-ins remain available if Adobe cannot
load at this address. Browser history has separately documented recovery limits.
