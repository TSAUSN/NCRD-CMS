# Echelon reference photos

Use Echelon's own Media records for the approved template pictures.

For: Admins and Super admins. Last checked: 2026-11-01.

The local template import uses 11 raster files from the supplied Echelon assets
folder. It excludes the unused outer banner and reuses the existing shared
shield. Each record has a readable name, description, focus point and source.
The original source files stay unchanged; normal Media processing makes the
original, thumbnail, Card and Wide versions.

In Echelon Media, choose the Echelon reference folder. Photos borrowed for the
chapter example carry a needs replacement tag and a note explaining why.
Replace those with chapter photos before public hosting. Confirm photo rights
before hosting any of the reference pictures. Do not use SAWSO story photos.

Choose photos through the usual picker. Check Card, Phone and Wide previews,
then save the page as a draft. Importing a picture never publishes a page.

The operator's explicit local import checks reviewed file hashes and records
completed uploads. A repeat verifies existing records instead of adding
duplicates. A changed file, removed record or changed source needs review.
An interrupted run keeps its completed records so it can resume safely.
The import is not part of startup or a background sync.
