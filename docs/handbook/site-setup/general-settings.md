# General settings

Site details stay private until reviewed publication.

For: Admins and Super admins. Last checked: 2026-11-02.

Open Settings → General. Edit the site name, description for search, country,
language, contact email, phone and mailing address. Description allows155
characters. A blank country or contact field makes no claim about the site.
The language changes the language declared by the public page; it does not
translate the words. A page's own description takes priority over the site
fallback. Header & menu owns the logo, menu and Donate button. Contact fields
are stored with the site; they do not replace text on public pages or route
contact form messages. Edit the page or Footer to change what visitors see.

Save draft keeps the current site unchanged. Schedule and Publish open the
normal saved-change review. Leaving with unsaved fields offers Keep editing,
Save draft and leave, or Discard changes. A save conflict keeps the fields and
links to the saved settings in a separate tab. History provides normal release
recovery. Only Admins and Super admins can change these settings.

Publishing & approval contains Stories policy and chapter defaults/teams.
Review reminders contains the existing January/July chapter tools where set up.
Advanced contains addresses, people, scripts, backup and archive tools. Their
existing safeguards remain. Brought-in original-design sites keep their previous
Settings screen. Google hosting is planned separately; this screen does not
configure hosting or change DNS.

**Contact messages** appears on sites with a CMS contact form. Site admins and
Super admins can read the submitted message, reply address and received time.
The CMS saves these messages to this inbox; it does not forward them by email.
Assign an admin to check the inbox and respond through the site's normal process.
The inbox contains visitor information, so do not share screenshots or exports.

Archive is under Settings → Advanced. After archiving, native Settings shows
“This site is archived.” Content and settings history remain available. Its
public addresses stop serving; saved page bookmarks open in a read-only view.

Redirects stays inside Settings on native sites. Add an old path and choose a
page on this site, or import a CSV with Old address and New address columns.
Review the import before applying it. Ready destinations work as soon as the
redirect is saved; draft destinations wait for that page's publication. Edit or
Remove changes only that redirect. The table shows saved destination availability.
Chapter defaults, teams and check settings also apply on save; Stories policy
remains a draft until publication. Each section states its own save behavior.

Chapter publishing and review settings also offer Keep editing, Discard changes
and Save draft and leave. Leave-save keeps choices only in this browser under
your account and site. Chapter defaults, the new division name, each division's
new-staff entry and check settings have separate copies. Reopening their
section restores the choices. Use its Clear saved control to remove that copy
and return to the current form's opening values. Storage failures keep your
fields. Discard returns to opening/last browser-saved values without deleting
an earlier saved copy.

Use Save chapter defaults, Add division team, Add division staff or Save check
settings to apply a change. Those actions take effect immediately; leaving never
executes them. A restored older defaults/check revision cannot replace newer
settings. Reload, clear that saved copy and review again before applying. Saving
one form preserves another's unfinished work. Removing existing staff keeps an
unfinished new-staff entry. The explicit staff commands send no email.

Email preview tabs, month and year are read choices. They need no draft save.
Record contact check and Record waiting review messages remain explicit local
commands; neither applies or discards unsaved check settings. Leaving records no
messages. While an action is pending, wait for its result before navigating away.
