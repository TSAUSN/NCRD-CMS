# Search & sharing

Review verification tags and search hints before putting them on every page.

For: Admins and Super admins. Last checked: 2026-11-01.

Open Settings → Search & sharing. Paste the verification meta tag supplied by
Google, Bing, Yandex or Pinterest. Supported tags have a quoted name and content;
use each service once. Other markup is refused. Hints for search engines are
optional plain words. They are saved as metadata, without a promise that search
engines use them for ranking.

Save draft keeps these values private. Schedule and Publish open the normal
review of the saved Settings version. Confirm before the public head changes.
Clear a tag or the hints and publish the reviewed change to remove that metadata.
Leaving unsaved fields uses the same three choices as other Settings tabs. An
invalid paste stays on screen if saving is refused. A conflicting save preserves
your fields; check the saved settings in another tab before reloading.

View sitemap opens an authenticated XML preview of published page addresses.
Unpublished pages are excluded. The same XML formatter serves a site's public
sitemap. Public staging addresses intentionally return no sitemap and keep their
noindex rule. A public sitemap requires the site's live, indexable address.
This local work does not create or connect that address.

Each page keeps its own description and automatic canonical address. These
settings add no analytics, scripts, tracking service or additional network host.
Local checks verify draft/public metadata, clearing, XML access and staging
behavior. Search-service ownership acceptance and indexing on a future live
Google-hosted address are not verified here.

Redirect setup and spreadsheet source have private browser recovery. Cancel,
Escape and CMS departures offer Keep editing, Discard changes, or Save draft and
leave. The save keeps choices for this account/site only; it activates no route.
Reopen the same Add/Edit redirect or spreadsheet step to resume. Clear saved
setup/source removes recovery; failed browser saves or clears keep the fields.
Keep the original CSV file too. Restoring a spreadsheet requires Preview redirects
again; an old row preview is never saved. Refused imports refresh current routes
and return to Preview. Check the rows before explicitly importing.

A restored Edit keeps its original revision check. If another person changed
that redirect, the old setup cannot overwrite it. Check current redirects, clear
that saved setup and reopen the current row before making the intended change.
Only Save redirect or Import applies routing. These actions can affect visitors
immediately for published destinations; they remain separate from leave saves.
