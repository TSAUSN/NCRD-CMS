# Report stories, country lists and financial rows
Use shared report sections to edit stories, messages, country lists and financial statements.
For: Editors and Site admins. Last checked: 2026-11-03.

Choose Letters with full message or Financial summary from the library.
Open a letter or named row in the panel; change its content, then choose Done.
Each letter has a photo, description through the picker, name, role, introduction,
full message and source line. The message opens without JavaScript.

Financial summary has Expenses, Revenue, Financial position and Financial
activities lists. Add, remove or reorder a row; choose Amount, Total or Group
heading for a statement row. Amounts update the bars and revenue chart.
Use the report’s exact amounts and reporting period, and keep its source line.
Save draft, Schedule and Publish use the normal page review. A financial draft
stays private until published. Report-reviewer approval is required for the retained
2026 report before publication. The complete report is assembled as a private draft for source comparison.

Report photos are imported from the approved local assets once, with descriptions
and focus points. Choose them from Media inside the report; do not paste remote
picture addresses. Importing photos does not publish the report. The supplied
photos still need the report editor’s rights review before hosting.

Country story with stats keeps the country, title, photo and caption, story,
individual stat labels/numbers, impact list, related-story link and source in
ordinary content fields. Small country labels use a slightly darker red for readable
contrast; report bands and controls keep their approved red. An Admin chooses the response, feature, reading or
text layout; Site editors change the content. Open a stat in the panel to
change its number or use a number from Data values. Optional empty photos,
impact lists and related-story links do not add blank visitor cards.

Region lists with View all keeps the introduction, photo, disclosure label
and regional country lists together. Edit countries with the visual list
controls. Visitors can open the list with JavaScript disabled. The Global
Presence map uses the existing World View section separately; this country
list does not create another map. The retained report uses the same normal fields and the existing World View;
the content editor must review the source copy, photos and figures before publication.

Page links bar builds its links from visible sections with a heading and a
current link name. Their order follows the page. Change a heading to update
the link words, or set a shorter Page link label on the report section; an Admin uses the section menu’s Change link name to name a
destination. Earlier link names keep old addresses working but do not add
extra navigation items. Hidden and unnamed sections stay out of the bar.
The phone list label is a normal content field. Its list opens without
JavaScript; visitors follow the same section links at both widths. An empty
bar does not appear on the visitor page. There is no list of links to maintain.

The report also uses normal cover, text/photo, tiles, Stats, Contact cards, FAQ
and closing sections. The report layout shows their relevant fields, including
photo credits and member counts. Open the page at Desktop or Phone width to
check every disclosure. Saving a draft keeps the report private.

Annual Reports uses compact rows with Web page and PDF fields. Visitors see
View page, View PDF, or both, according to the destinations you have added.
Choose Change beside Web page to select a published page or enter its address.
For PDF, change the file address or choose Replace PDF to use the site's normal
PDF picker. Its summary shows the filename; the full address stays in Change.
Clear a destination to remove that button. Changes stay in the page draft.
Publish the reviewed report page before publishing its link on Annual Reports.
Earlier descriptions and photos remain saved when a row adopts this layout.

The cover's Download PDF keeps its secondary button treatment in both the editor
and public page, even when the first action is omitted. Story impact links use
the report's normal button treatment. Directory View members controls retain
the source plus mark and open without JavaScript. The report keeps its declared
54px desktop and 43px phone cover heading; the inherited SAWSO fonts and local
fallback remain in place.

Embedded World View and Split View sections keep their normal story-card
titles, links and button styles. Report typography applies to report content.

The complete report keeps each reading story’s heading, words and numbers in
one column, beside its photo or lead heading. Program reading stories use the
source’s wider lead column. Response statistics follow the opening copy and
photo, and the closing quote uses its source frame. These layouts keep the same
editable fields and saved-number choices. Portraits align at the bottom of their
frames, as in the supplied report. Standalone sections keep their library layout.

The impact photo stays beside its introduction on phones. Directory titles and
member counts share one row, with View members below. Phone text and the report’s
spacing follow the supplied source; editing uses the same fields.
