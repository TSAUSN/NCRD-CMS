# Add a section

Choose its place, see the sample on your page, then add it to the private draft.

For: Site admins and Super admins. Last checked: 2026-11-02.

Choose a section’s More menu and Add above or Add below. The library opens on
the left and says where it is adding. Change spot shows blue Add here lines
on the page. Choose a line to return to the library. Add at end remains a
shortcut in Page structure.

Search sections also accepts the approved Symphony names. Theater Space finds
Hero slider. Category and Favourites help narrow the existing library. Page
templates and the saved section clipboard remain available beside it.

Drag a library card onto the page to preview it at that spot. The draft stays
unchanged until you choose Add this section; Cancel removes the preview.

Choose a section to see its sample text at that spot on the real page. The
catalogue stays visible. Move up or Move down changes its place. Cancel, Done
or Escape removes the preview without creating a draft item and returns keyboard
focus to the opening control, or to Add in Page structure when that control is
no longer available. Add this section
adds it once through the normal draft save and History flow. Replace its sample
words and pictures before publishing. Publish still shows its review first.

A preview that fails explains the problem and offers Try again. Add stays
unavailable until it loads. Code-based isolated pages currently require a
standard layout or their existing separate preview; this new inline insertion
preview does not run a site’s scripts. Imported sites keep their earlier library.

The library takes the place of Page structure while it is open. Use the page
preview and Change spot to choose a location. Your page content stays visible
beside the library. Editors and Content creators can edit existing content;
ask an Admin when the page needs a new section.

In Advanced section authoring, visual and HTML tools keep separate local drafts
while you switch modes. CMS departures offer Keep editing, Discard changes, or
Save draft and leave for each unfinished tool. Discard returns that tool to its
opening fields. Saving uses the normal library command: check the current preview
and describe what changed first. A failed or stale save keeps the fields and
requested departure open. Wait for previews, file reads and saves to finish.

A saved section/version becomes available in Sections. Existing page content
and published pages keep their chosen versions; review updates on those pages
separately. Leaving never publishes a page or relaxes authoring rights. These
Advanced tools do not add source controls to an Editor's page panel.
