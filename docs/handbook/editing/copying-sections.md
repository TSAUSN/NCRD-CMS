# Copy a section to another page

Put a section’s text and settings at a chosen place on another private draft.

For: Site admins and Super admins. Last checked: 2026-11-01.

Choose the section, open More and choose Copy to another page. Choose another
ordinary page on this site and Where on that page. The place list shows the
real section names and where the copy will go. Copy section saves that page’s
draft. It leaves the source and the live pages unchanged.

Tags stay the same. Review copied story settings on the destination page.
The copy gets a unique section link name if needed; earlier names belong to the
source and are not copied. Open the destination in the provided separate tab
and check its content before publishing.

If the destination changed, reload its places and choose again. If a copy could
not be confirmed, check that page’s draft before trying again. Cancel leaves no
copy behind. Back and Done keep the page edits you made before this step.
The existing Copy section/Paste copied section path in this browser remains.

The isolated Chromium and WebKit section journeys pass. The numbered final
walk stays open. The older WebKit editor journey reported a cancelled save
response during the section-links piece; its navigation fix also passed the
next touched library-piece WebKit run, without repeating that earlier run.
