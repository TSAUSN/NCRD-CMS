# Story tags

Organize stories with this site's own tags, keywords and map regions, then publish the draft changes.

For: Site admins and Super admins. Last checked: 2026-11-02.

Open Stories, then Manage tags. SAWSO calls its two groups Project Sectors and
Regions. Another site can use its own names through Rename level. Editors and
contributors do not see Manage tags and cannot change these settings directly.

Add a tag and give it a name. Enter suggestion words or phrases separated by
commas. For a region, choose the World View map areas it covers. If regions
share an area, the first region in the list is used there. Save the tag; Cancel
or Escape leaves no new tag behind. Open the row's Actions menu and choose
Rename to edit its name, keywords and map areas. Hover a shortened name, ID or
keyword preview for its full value. A rename keeps existing story assignments and page filters connected.

Drag the grip to reorder tags. With the grip focused, Alt + Up or Down moves it
with the keyboard. The row's Actions menu → Delete offers two choices: move stories to another tag in
the same group, or just remove the tag. Choose one of its cards, then Delete tag. Stories retain their other tags, text,
photos and source addresses. A page filtering by the deleted tag is not
automatically switched to another one; choose a replacement filter on that page.

Re-suggest tags for unreviewed stories asks for confirmation, then replaces only
unreviewed stories' tags using the saved keywords. Reviewed stories keep their
tags. Suggestions use title and description, matching whole words or phrases.

Each completed action saves a private draft. Publish… opens the existing review
queue; opening it does not publish. If another person changed Stories, reload
Manage tags before saving again. Done returns to Stories. There is no automatic
public-feed refresh, embed code or external sign-in on this screen.

The new workspace's click-to-tag list, refresh, map, Split View and calendar are
still in progress. Their required real-app acceptance remains open; this guide
does not certify all Stories requirements or the final numbered checklist.

The current TagManager comparison at 1440/1024 uses shared navigation, buttons,
row menus and region checkboxes. Normal saves still preserve identities and
story assignments. The final numbered acceptance and reviewer visual sign-off
remain open.

If you choose another CMS destination while a tag or group-name edit is open,
Keep editing returns to its fields. Save draft and leave checks the name,
keywords and map areas with the usual save command, then opens the destination.
A save failure keeps your fields on screen. Discard changes closes the unfinished
edit and creates no tag. Saving privately still waits for Publish to change the
public site. Browser history retains the separately documented recovery limits.
