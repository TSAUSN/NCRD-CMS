# World View

Show stories by region on a map, with the same choices available as plain links.

For: Site admins and people allowed to edit the page. Last checked: 2026-10-31.

Site admins first turn on Stories and set tag names and map areas in Manage tags.
Save and publish those changes through the normal review. Other sites use their
own tag names; no SAWSO tags or photos are borrowed.

Add World View from the page's section library. Set Heading above the map,
Region shown when the page opens, Stories per region and the main tags to include.
None, ask visitors to pick leaves the choice to the visitor. Leave the main-tag
group empty to allow any. Changing a main-tag filter changes the counts as well
as the cards. Stories per region limits the cards after choosing the region.
All shows the matching stories in the section's source. SAWSO sector pages show
up to6 stories per region, including when All is selected; the picker explains
that limit. Counts still include every matching story. Feeds keep the agreed
13-month date window and this site's published review/visibility settings.

The map and counts come from this site's stories and saved region areas. Regions
with no current stories stay grey. Pins count stories by region, including a
story tagged with several regions. The heading may sit on grey; the map and
cards sit in one white container. Labels under the cards use this site's tag names.

Save draft, then review and publish the page and any pending story/tag changes.
The page remains private until its release. The page preview can use saved drafts;
public pages keep published choices. An unavailable starting region returns to
the region chooser. Map labels and counts are generated; edit a region's name
or area in Manage tags rather than trying to change a map label on the canvas.

Visitors can choose a map region or its text link. Without JavaScript, the link
opens the selected region as a normal page. With JavaScript, map controls replace the duplicate text links and the section
updates in place and shows Loading stories. A failed request keeps the current stories,
with Try again and Open region. Reduced motion disables smooth scrolling. Several
maps on a page keep separate choices in the address. Private visitor-preview
links stay within the private preview; they do not publish or read the public feed.

In Stories → World View, choose the same settings and inspect a private preview.
Choices stay in the address when you reload; they do not change a page. The preview
uses saved draft stories and the site's design, with plain region links. If you
open a story inside it, use Back to map preview. Preview at the top opens the
full-size view. If loading fails, choices remain available with Try again.

Site admins can choose Add to a page, search for a page and choose Add as draft.
The section goes at the end; open the page to move it, review and publish. Cancel
or Escape adds nothing. Story articles and chapter pages are not choices. Editors
can try the preview and ask a Site admin to add the section. A changed page stops
the save and asks you to reload choices; it does not replace someone else's work.
If a response is lost, repeat Add as draft with the same page choice to find the
saved addition rather than create another. A new confirmed addition after reloading
page choices is a separate edit.

Split View, Coming up, the complete Stories acceptance walk and broader editor
role/layout cleanup remain required.

The section library includes an offline fallback thumbnail for this layout.
It is a neutral library preview, not content added to the page.

Automatic source counts cover the full supported Story library, up to2,000
entries. All and the news views can reach past 200; the old saved All setting
continues to work. SAWSO sector pages still show at most6. Private previews use
the same complete pool. Existing published snapshots refresh through normal
publication. This does not change article text or ordinary feed limits.
