# Cards and repeated content

Edit one card at a time while the page keeps its real layout.

For: Site editors, Admins, Super admins and assigned page editors within their access. Last checked: 2026-11-03.

Choose a native card section, then choose a row in Cards. The panel contains
that card’s fields, with the other section fields temporarily set aside. Back returns to the list; Done keeps the card in the draft.
The page’s section title and other cards stay in place. The existing photo
picker, focus point and crop previews remain available wherever the card has
a photo, and the existing icon picker keeps its search and recently used choices.

Adding or removing cards keeps the section's existing columns and card design.
For example, a sixth card wraps below an existing five-column row. It does not
turn the first five cards into a different design. This adds no style choice to
the content panel.

Add a card starts exactly one empty card. Its content appears as you type.
Cancel, Back or Escape removes that new addition and its fields. An untouched
addition is also removed when you select another section. Typed work is kept
as a draft if you move away, and still needs review before publication. Done
stays unavailable for a completely empty item. Nothing publishes from this panel.

Use row actions to move, duplicate or remove a card. Dragging is another way
to reorder. Duplicating retains the chosen card’s content. Removing an existing
card obeys the template’s minimum; cancelling a new item restores the previous
list even when it had not reached that minimum. History and the editor’s Undo
remain the recovery paths for saved or current work.

Native pages keep Add card in the panel. Selection controls sit outside the
page content, and no Add card tile is inserted into a real grid. This prevents
a five-card row from changing into three columns simply because it was selected.
Brought-in sites retain their existing editing flow while their public design
remains frozen. These display changes do not grant any new write permissions.

The page list now stays visible and starts collapsed. Clicking the section
title opens its focused title panel; Back returns to the full content panel
and Add a card. Native header/footer clicks lead to their shared-area notes.
The wider editor pass still includes role-specific tabs and three-choice leaving
behavior. See titles-and-links.md for the nested Change dialog. This guide does not claim
the full EditorClean or final numbered acceptance is complete.

Checked locally at 1440 and 1024 in Chromium and WebKit: native Home card/list
selection keeps its geometry; additions, cancellation and exactly one kept card
work. The first five cards retain their presentation after a sixth is added,
saved and reloaded. Photo focus, chapter permissions and inspector controls pass.
The earlier unverified WebKit portions now pass in the touched card journey.
Final numbered acceptance and reviewer visual review remain separate checks.

Section and card Back/Done controls stay in the same fixed panel header. In a
card, they apply to that card; at the list, Done returns to the page. Choosing
an icon has Cancel and Escape, which keep the card's other unfinished fields.

A blank optional Introduction starts collapsed so the cards list is easy to
reach. Open **Introduction (optional)** or choose Introduction in Page structure
to write it. An introduction that already has words opens with the section.
The same visual formatting and normal Save draft/Publish path remain available.

Card rows show their saved icon and a short single-line title. Hover for the
complete title. Open the row for every field; its Actions menu keeps move, duplicate
and removal commands. These summaries do not shorten the saved content.
