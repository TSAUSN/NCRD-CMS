# Split View

Offer three ways to browse the site's saved stories on one page.

For: Site admins and people allowed to edit the page. Last checked: 2026-10-31.

A Site admin adds Split View from the section library. Set Heading, Introduction,
View shown first and Stories per Show more. The main-tag view uses this site's
own tag name; SAWSO calls it By Project Sector. The section uses this site's
Stories library. Hidden/removed stories, future dates and stories beyond13 months
stay out; the site's reviewed-story setting applies. Review and publish the page
and pending Story/tag changes through the normal publishing screen.

Recently Published starts with the chosen number of newest stories. Show more
keeps the earlier cards and adds the next group. With JavaScript, Show tags
switches hide or show main and secondary pills; the browser remembers the choice.
Without JavaScript, all tags remain visible and Show more is an ordinary link.

The main-tag view shows tiles for tags with current stories. Choose one to see
its cards. By Map uses the saved region areas from Manage tags; grey areas have
no current stories. Pins count by region, including stories with several regions.
View, tag and region links can be saved or shared. Several widgets keep separate
choices. The source uses the existing200-story binding bound; SAWSO sector pages
show at most6 cards while counts describe their matching source.

Enhanced views update in place, show progress and preserve current cards when a
request fails. Try again retries that choice; Open stories uses the normal link.
Keyboard users can move between tabs with arrows, Home or End. Show more focuses
the first new story. Reduced motion disables animated transitions and scrolling.
No public source check happens while browsing or changing these settings.

Open Stories → Split View to try the same four settings before adding a section.
Choices stay in the address when you reload and do not write page content. Scroll
the preview to see the full section, or choose Preview for a larger view. Cancel,
Done or Escape returns to the same choices. If you open a story inside the
preview, Back to Split View preview returns to the configured section.

Site admins choose Add to a page, search for a page and confirm Add as draft.
Cancel adds nothing. Story articles and chapter pages are excluded. If another
editor changes that page, reload page choices before saving; their work is kept.
A lost response can retry the same page choice without adding a duplicate. Open
the saved page to move the section, review and publish. Other roles can try the
preview and ask a Site admin to add it. No source check happens in this flow.

SAWSO's Newsroom uses this same section with the approved heading and introduction.
Switching the existing page stays a draft until normal review; its address,
metadata and menu position stay the same. Publish the saved Story tag catalog
with it so the map can use the saved region areas. Existing sector/region links
still open matching cards. Earlier combined filters and searches show a short
notice with Show all stories. Earlier page numbers expand Show more; old view
bookmarks open the chosen view and use the current address format.

Home keeps its existing section. The complete Stories acceptance walk remains
required.

The section library includes an offline fallback thumbnail for this layout.
It is a neutral library preview, not content added to the page.

Automatic source counts cover the full supported Story library, up to2,000
entries. All and the news views can reach past 200; the old saved All setting
continues to work. SAWSO sector pages still show at most6. Private previews use
the same complete pool. Existing published snapshots refresh through normal
publication. This does not change article text or ordinary feed limits.
