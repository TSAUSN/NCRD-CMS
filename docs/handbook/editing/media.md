# Image details

Describe and organize an image without changing page or story drafts.

For: People with Media editing access. Last checked: 2026-11-02.

Choose an image in Media to edit its description, decorative choice, folder,
focus point, tags, credit and rights note. Save image details updates the Media
library immediately. Existing saved page and story placements stay unchanged.

If you leave with changes, the CMS offers Keep editing, Discard changes or
Save and leave. A missing description or failed save keeps your fields open.
Wait for the save and library refresh to finish. The same choices appear when
closing details, opening Used on or starting replacement. Native Media also
checks before switching images, searching or changing filters. Discard resets only
the unfinished form. Replacement and deletion still have their own reviews.

Verified locally in the app with an Editor account and isolated records.
Native Media keeps the grid beside a nonmodal Image details panel. Close or
Escape returns to the grid. At 1440/1024, Save image details stays at the bottom
of the bounded panel while fields scroll. Imported sites keep their modal
drawer. Library, Tag and Sort are under More filters; status and Grid/List stay
visible. Refresh library retries a failed load without repeating a write.

The drop notice accepts JPEG, PNG and WebP images. PDFs keep the Documents tab.
There is no Toolkit integration. Existing descriptions, focus, usage and reviewed
replacement stay available. Compare actual retained photos at both desktop widths; reviewer visual sign-off and final acceptance remain open. No hosting or live site was changed.

Choosing a file starts unfinished upload work. Close upload, the panel close
button, or leaving the CMS offers Keep editing, Discard changes or Save and
leave. Saving runs the ordinary upload and adds the file to this site's Media
library immediately. It does not place it in a page or story. The server still
verifies the bytes and processes responsive images before the file is ready.

A missing description or failed upload keeps the selected file and description
here. While an upload is being accepted, wait for the result before leaving.
Once accepted, its description is fixed in this form; edit the ready image's
details later, or choose Upload another for a new file. Discard removes only
the unsent local selection. Removing an accepted file from this form does not
delete it from Media.

The same choices protect uploads inside the page, logo and replacement image
picker. Closing that picker checks the upload only and leaves parent page work
alone. Saving there adds a library file without inserting or replacing any
image. If an earlier upload becomes ready while you are describing another
file, the new unfinished form stays open.

Select images to move them to a folder or add tags together. Apply organization
updates Media immediately and keeps page/story placements unchanged. Unfinished
folder or tag input offers Keep editing, Discard changes or Save and leave
before you clear/change selection, search, filter or leave the CMS. Discard
returns to the last applied input choices; Save and leave applies organization
to the currently selected images through the ordinary permission/revision checks.

If a selected image has changed elsewhere, or the request fails, your input and
selection stay open. Check and refresh the library before retrying; no partial
bulk change is claimed. A confirmed save followed by a failed library refresh
says the images were organized and asks you to refresh without repeating it.
Once the server has confirmed the organization, leaving can continue.

Native Media checks unfinished image details before starting bulk work. It
closes the details panel to leave room for the active form. Selecting an image
to edit its details checks bulk input first. An unfinished upload also remains
open when organization finishes. During a save, wait for its result. Apply or
discard organization input before deleting selected images; Discard organization
changes keeps the selection, while Clear selection can leave the bulk step.

In Documents, an unfinished PDF category offers Keep editing, Discard changes or
Save and leave before choosing another PDF, applying search or filters, paging,
refreshing, starting an upload or leaving the CMS. Save and leave uses Save
category's normal revision check and updates the Media library immediately.
It changes no page/story draft or publication and keeps the PDF's bytes and link.
Discard returns to the selected PDF's saved category.

A failed or stale category save keeps the PDF and your input selected. Keep
editing to review the error beside the category, or choose Refresh list and
discard the old input to load the newer library record. A confirmed update
followed by a failed refresh says it was saved; refresh without repeating it.
Resolve the category before Archive document or Restore to library. Uploads
and metadata saves block departures while their result is pending. Uploading a
replacement still adds a separate PDF; choose it explicitly in the content draft.

Grid keeps photos, one-line file names and processing status compact; hover a name
for its full value. List shows folder/dimensions, and More details holds tags,
credit and rights. More filters opens below the status/view commands. Shared
controls also apply to Upload an image and Documents. The Documents inspector
stays beside its library at 1440/1024, with its link, category, reviewed archive and
Replace in a draft controls. A successful upload can still be refreshing the
library; wait for the file control to become available before choosing another.
