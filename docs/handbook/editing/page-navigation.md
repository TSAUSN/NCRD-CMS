# Page navigation and panel width

Keep the page list beside the preview and open one section at a time.

For: Site editors, Admins, Super admins and assigned page editors. Last checked: 2026-11-02.

On a native page, the left page list stays visible at 1440 and 1024. Sections
start collapsed. Choose a section to jump to it and open its fields; the
previous section folds away. The small disclosure opens or closes a section
without moving it. Search still finds every field and destination, including
words inside cards. Search and Changed only may expand matching rows so their results are visible.
Open Page structure options in the search box for Changed only and Collapse all.
Collapse all returns an unfiltered list to its short form.

Each native card has one row. Choosing that row opens the complete card,
including its photo, words, link and icon where supported. Hero slides keep
one row per slide. All grouped fields retain their original selection and
changed-state identities; no saved content is grouped or rewritten.

Each section’s Actions menu keeps Show or Hide and Move up or Move down,
including the existing Alt+arrow keyboard path. Dragging sections and the insertion gaps remain
available where the role permits them. Nonselected native rows omit those
extra controls to keep navigation short. Brought-in sites keep their existing
list and responsive controls while their design is frozen.

Drag the panel divider or use its arrow keys to widen the panel. Its preferred
width is remembered in this browser. Native pages limit that width when the
window is smaller so the page list and a visible preview still fit beside it;
the larger preference returns when the window allows it. Below tablet width,
the existing Structure, Page and Edit choices remain available.

The native editor clips outer workspace panels without making them scrollable
containers. Selecting content scrolls the page inside its iframe; the header
and external selection toolbar should stay visible. Final real-app acceptance
and the wider title/link, role and frame-handoff work remain separate checks.

When leaving through a CMS link, choose Keep editing, Save draft and leave, or
Discard my edits. After autosave the save choice says Keep draft and leave.
Discard restores the private draft from when you opened this page, keeping any
private work that was already there. It does not publish. If someone else saved
meanwhile, discard stops and keeps your words; check saved History before trying
again. Keeping a draft removes only newly inserted untouched cards and slides;
words you typed and pre-existing items remain. Browser Back/Forward integration
and the rollout to every other writing screen are still being completed.

The native editor's top bar keeps saved state, History, Preview, Save draft,
Schedule and Publish together. Undo/Redo and Desktop/Tablet/Phone sit above the
canvas. All sites stays available in More page actions. At 1440 and 1024, the page
list, canvas and Inspector stay visible without redundant pane tabs. Narrower
windows retain their existing panel choices.

With nothing selected, This page lists the saved sections. Choose one there or
in Page structure to jump to its fields. Add a section uses the existing library
where your role permits it. Header & menu explains the shared header/footer;
Page checks keeps readiness and Site look available. A failed readiness report
opens its checks. Page settings remains a separate drawer and all selection,
Back/Done, save, review and publication commands keep their existing behavior.

The opening feature section is called Hero slider. Deliberate custom section
names remain. History, Preview, Save draft, Schedule and Publish share the editor
bar. With no selection, Add a section fills the This page panel; its gear opens
Page settings. Page checks and optional fields use the same disclosure style.

Fields stay quiet until hovered or selected. Zoom stays below the preview, so
it cannot cover the page. A narrow canvas reserves a second tools row to keep
the page in place when you select something. Admins find Change layout under
Style. Content roles keep their existing content fields and approval path.
