# Links to sections

Copy a section link or change its name without losing the related drafts.

For: Site admins and Super admins. Last checked: 2026-11-01.

Choose a section and open More. Copy link to this section copies its existing
address. If the section does not have a link yet, choose and save a link name.
Use lowercase letters, numbers and hyphens, starting with a letter. The link
opens the page and scrolls to this section. Publish before sharing new links.

Change link name opens the same remembered-width panel. It lists the saved
links and drafts that will change. Save updates the name and its related page,
menu, header/footer and list destinations as drafts. Nothing is published.
Review the affected drafts together in Publish. The earlier names keep working
when the source is published before older referring pages.

A related draft changed? Reload the step to compare its latest saved links.
A changed source page asks you to return and reload the page. A shared link
whose destination is ambiguous, or formatting the CMS cannot safely preserve,
needs a manual review before renaming. Plain prose and unrelated URLs stay.

Back and Done use the shared unfinished-work choices for this step. Cancel
removes only the proposed name; the page edits you made before opening stay.
The underlying page and its actions are paused until this step is finished.
Done reloads the renamed page to show its saved draft. The normal saved
checkpoints remain in History; the page edits made before this step stay saved.

The isolated Chromium and WebKit section journeys pass. The numbered final
walk stays open. The older WebKit editor journey reported a cancelled save
response during the section-links piece; its navigation fix also passed the
next touched library-piece WebKit run, without repeating that earlier run.
