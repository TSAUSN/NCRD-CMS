# Shared header, footer and menu

Change shared areas from their site screens while your page edits stay in place.

For: Content editors, Site admins and Super admins. Last checked: 2026-10-31.

On a native page, click the header or footer to see how many pages use it.
The note contains no editable menu, name, tagline or logo fields. Back, Done
and Escape return to the page. The page remains in the same editing session.

A Site admin or Super admin can choose Open Header & menu or Open Footer.
The site screen opens in a new tab. Return to the original tab to keep editing
the page, including work that had not yet finished saving. Editors see the
shared-area note and the explanation that a Site admin manages it; they receive
no site-screen link. Direct Header/Footer routes keep their existing access checks.

Page details shows the page’s saved menu location and, for Site admins, a link
to Header & menu. It cannot add, remove or rename a menu item. Saving its title,
address or parent keeps the current menu, even if it changed in another tab.
Publishing a renamed native page also preserves its existing automatic menu
labels. Navigation still follows page identities when an address changes.

New page retains Add to the menu when it’s published and uses the existing
menu commands. First publication and removing unavailable pages retain the
existing automatic navigation engine. A removed or unpublished page must not
leave a working-looking link to unavailable content.

Brought-in sites keep their original Menu & footer editing path and page-details
behavior. Native Site look edits appearance and links to the dedicated Header &
menu and Footer screens; it cannot save shared text or navigation. A template's
page layout stays fixed. The national palette retains its explicitly approved
red/white pair, with the measured contrast still shown. Other colour pairs must
meet the normal contrast checks. Broader Colours/Buttons layout and role-specific
editor panels remain separate Round 3 work. The final numbered acceptance walk
is still required; development checks alone do not mark it Pass.
