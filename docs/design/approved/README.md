# Approved mockups

Optional. The maintainer adds a mockup here when a built screen should look
different; builders then match it. Mockups can come from anywhere, including
[../screen-briefs.md](../screen-briefs.md).

Name files `<screen-id>-<short-name>.png`, for example
`S4-editor-section-selected.png`. Add a line below for each approved file
with the date and any notes. The latest approved file for a screen ID wins.
