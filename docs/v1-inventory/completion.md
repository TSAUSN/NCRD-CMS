For each row, record the assigned owner and one disposition: supported directly, supported through reviewed adaptation, retained external application, or explicitly approved exclusion. A pending disposition stays open. Save implementation/test evidence, source/content hashes and desktop/tablet/phone visual plus interaction evidence. Saved authored values, icons, links and repeat records are part of acceptance, not only default markup. Exceptions require a decision reference and user-visible limitation.

Keep `source_classification` as dated evidence; a later importer run needs its own run/manifest and classification update with history. `status` means product closure and must not be derived mechanically from source classification. Reason counts overlap. Reruns must reconcile added/removed definitions and authored templates rather than quietly dropping rows. CSV rows contain data only, not instructions to relax rendering policies.
