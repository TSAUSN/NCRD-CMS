Generated by scripts/current-sql.mjs. Do not edit or apply these files.

This is one current definition for each of the 549 application functions,
read with `pg_get_functiondef` after 209 immutable migrations. Each file records
its owner and ACL. [catalog.sql](catalog.sql) contains schemas, types, tables,
constraints, indexes, RLS policies and grants; function bodies are linked below.
It is a reading reference, not a replacement installer or a migration.

To change behavior, add an immutable migration and real-role database tests.
Regenerate from a freshly migrated disposable database with:

```bash
CURRENT_SQL_DATABASE_URL=postgres://cms:cms@127.0.0.1:54329/cms_e2e_refactor pnpm schema:reference
pnpm test:db
```

`pnpm schema:reference:check` refuses stale/missing/extra generated files; the
database suite checks the reference against a fresh migrated clone. Dump client
version comments and random transport guards are omitted from this documentation.
The independent golden schema retains every SQL byte and owner/grant/policy.
Numbered migrations remain the only runtime authority.
